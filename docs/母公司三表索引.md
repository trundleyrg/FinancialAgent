# 中国证券市场母公司财务报表标准格式索引

> 本目录收录上市公司在编制**母公司财务报表**时依据的标准格式文档。
> 母公司报表反映单一法人视角，与合并报表在项目结构、编号、特殊项目上存在显著差异。

## 文档清单

| 文档 | 内容 | 与合并表差异要点 |
|---|---|---|
| [母公司资产负债表标准.md](./母公司资产负债表标准.md) | 单一法人视角；长期股权投资按成本法；不含少数股东权益 | 无"少数股东权益"与"归属于母公司所有者权益合计" |
| [母公司利润表标准.md](./母公司利润表标准.md) | 项目编号一/二/三/四/五/六/七（合并表为 一-八） | 不分"归属母公司/少数股东"；投资收益主要为子公司分红 |
| [母公司现金流量表标准.md](./母公司现金流量表标准.md) | 不抵消集团内部资金往来 | "取得投资收益收到的现金"主要为子公司分红；不含少数股东相关明细 |

## 关键概念

### 母公司报表与合并报表的总体差异

| 维度 | 合并报表 | 母公司报表 |
|---|---|---|
| 反映主体 | 集团（含子公司） | 单一法人 |
| 长期股权投资 | 抵消后按权益法 | 按**成本法**（投资成本不变） |
| 内部往来 | 已抵消 | 完整列示 |
| 未实现内部损益 | 抵消 | 不调整 |
| 少数股东权益 | 单列 | 不存在 |
| 投资收益 | 权益法（含联营/合营） | 主要为子公司分红（成本法） |
| 现金流量 | 集团合并现金 | 母公司自身现金 |

### 母公司报表的项目编号体系

- **利润表编号**：合并表为"一/二/三/四/五/六/七/八"，母公司表为"一/二/三/四/五/六/七"
- 母公司表把合并表的"营业利润(三)"、"利润总额(四)"、"净利润(五)"前移为"营业利润(二)"、"利润总额(三)"、"净利润(四)"
- 母公司表把合并表的"每股收益(八)"前移为"每股收益(七)"

### 修订历史

母公司报表的修订历史与合并报表同步，主要参考：
- 财会〔2014〕6 号《企业会计准则第 30 号——财务报表列报》
- 财会〔2018〕15 号、〔2019〕6 号 / 16 号 财务报表格式修订
- 财会〔2023〕21 号、〔2024〕24 号 准则解释

### 母公司三表项目代码（src/db/models.py）

| 模型 | 表名 | 关键差异（vs 合并表） |
|---|---|---|
| `ParentCompanyBalanceSheet` | `parent_company_balance_sheet` | 无 `minority_interest`、无 `total_equity_attributable_to_parent_company` |
| `ParentCompanyIncomeStatement` | `parent_company_income_statement` | 无 `minority_interest_net_profit`、无 `comprehensive_income_attributable_to_minority`、无 `oci_attributable_to_minority` |
| `ParentCompanyCashFlowStatement` | `parent_company_cash_flow_statement` | 无 `capital_contribution_from_minority`、无 `dividend_to_minority` |

字段命名规范与合并表保持一致；help_text 与财政部报表项目名称严格对应；单位换算遵循 [docs/财报三表索引.md](./财报三表索引.md) 中的统一规范（人民币元）。
