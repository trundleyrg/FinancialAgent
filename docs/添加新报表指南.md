# 添加新报表指南

本指南说明如何向项目注册一张新报表。本项目支持两类查询资源：

1. **三表形态报表**（资产负债 / 利润 / 现金流量类，6+N 张）→ 注册到 `_STATEMENT_REGISTRY`
2. **其他查询资源**（不属于三表但走 ReportKey 寻址）→ 单独建 repo

---

## 判断标准

如果新表符合以下所有条件，应注册为 statement：

- 物理表结构包含 `(company_name, stock_code, report_year, report_period)` 标准地址字段
- 形态与现有 6 张三表相似（金融财务概念、可枚举字段、单位换算遵循《企业会计准则》）
- 期望被 `get_all_statements` / `get_multi_year_*` 等方法覆盖

否则（如结构完全不同或语义独立），应单独建 repo。

**举例：**
- "股东权益变动表" / "分部信息表" → statement
- "管理层讨论记录" / "审计意见元数据" → 独立 repo

## 步骤一：建 schema

在 [src/db/models.py](../src/db/models.py) 添加 Peewee 模型，遵守既有命名规范与索引约定：

```python
class NewStatement(Model):
    id = AutoField(primary_key=True)
    company_name = CharField(max_length=255, null=False, index=True)
    stock_code = CharField(max_length=20, null=False, index=True)
    report_year = IntegerField(null=False, index=True)
    report_period = CharField(max_length=10, null=False, index=True)

    # 报表特有字段...
    field_a = FloatField(null=True, help_text="字段 A")

    class Meta:
        database = db
        table_name = 'new_statement'
```

---

## 步骤二：注册到 `_STATEMENT_REGISTRY`

> 仅适用于 statement 路径。独立 repo 路径跳过此步。

在 [src/db/repository/statements.py](../src/db/repository/statements.py) 的 `_STATEMENT_REGISTRY` 字面量内追加一项：

```python
StatementSpec(
    "new_statement",              # 物理表名 = 模型 _meta.table_name
    "新报表中文名",
    scope="consolidated",          # 或 "parent_company" / 未来扩展值
    kind="other",                  # 或现有 "balance_sheet" / "income_statement" / "cash_flow"
    model_class=NewStatement,
),
```

`scope` / `kind` 取值约定：

| kind | 当前对应表 |
|---|---|
| `balance_sheet` | consolidated_balance_sheet, parent_company_balance_sheet |
| `income_statement` | consolidated_income_statement, parent_company_income_statement |
| `cash_flow` | consolidated_cash_flow_statement, parent_company_cash_flow_statement |
| `other` | 其他（自定义） |

| scope | 当前对应表 |
|---|---|
| `consolidated` | 合并表 |
| `parent_company` | 母公司表 |

新 kind / scope 值可自由扩展 — `by_kind` / `by_scope` 立即覆盖。

## 步骤三：配套工作清单

注册后还需检查下列文件是否需要补：

| 文件 | 检查内容 |
|---|---|
| `src/db/db_connector.py` | `_get_model_class` map（L376-389）需追加新表，否则 `insert_record` / `filter_records` / `drop_tables` / `TABLE_NAME_TO_MODEL` / `TABLE_TYPE_NAMES` / `export_tables_to_excel` 找不到新表 |
| `src/db/db_connector.py` | `_create_duckdb_tables` 的 tables 列表（L250-256）已自动包含（遍历 module import），无需改 |
| `script/init_duckdb.py` / `init_postgresql_db.py` | 模型 import 列表需追加新模型 |
| `src/db/db_connector.py` | PDF 解析时若该表可从 PDF 提取，需在 `TABLE_NAME_TO_MODEL`（中文名 → 类）和 `TABLE_TYPE_NAMES`（表名 → 中文名）补映射 |
| `ui/backend/services/db_service.py` | 若 UI 需要展示该表，在 `_TABLE_MAP` 追加 `<physical_table>: <ui_key>` 映射 |
| `src/agents/tools/db_tools.py` | 若 LLM 工具需查询该表，在 `_STATEMENT_ALIASES` 追加短别名（如需要）；否则按规范名调用 |

## 步骤四：测试

新增 statement 后，`StatementRepository` 的所有方法自动覆盖新表：

- `get_statement(key, "new_statement")` — 单查
- `get_all_statements(key)` — 同 key 全表拉取
- `get_multi_year_statement(key, "new_statement", start, end)` — 单表跨年
- `get_multi_year_all_statements(key, start, end)` — 跨年 × 全表

测试可参照 `tests/test_db_repository/test_statements.py` 中"动态注册"用例（`TestStatementRepositoryBasics.test_register_statement_visible_after`）。

## 不走注册表：独立 repo 模式

若新查询资源不符合 statement 形态（如 `share_structure`），按下面模式新建独立 repo：

```python
# src/db/repository/new_resource.py
"""NewResourceRepository — 新资源快照。"""
from typing import Any, Dict, List, Optional

from src.db.db_connector import DatabaseConnector
from src.db.repository.base import BaseRepository
from src.db.repository.keys import ReportKey


class NewResourceRepository(BaseRepository):
    """新资源（new_resource）。与三表同地址形态但独立 repo。"""

    def get_resource(self, key: ReportKey) -> Optional[Dict[str, Any]]:
        return self._query_first("new_resource", key)

    def list_resources(self, key: ReportKey) -> List[Dict[str, Any]]:
        return self._query("new_resource", key)

    def get_multi_year_resources(
        self, key: ReportKey, start_year: int, end_year: int,
    ) -> Dict[int, Dict[str, Any]]:
        out: Dict[int, Dict[str, Any]] = {}
        for y in range(start_year, end_year + 1):
            d = self.get_resource(key.with_year(y))
            if d is not None:
                out[y] = d
        return out
```

然后在 `src/db/repository/__init__.py` 与 `src/db/__init__.py` 追加 re-export。
