## 关键概念

### 编制原则

- **报表种类**：合并财务报表 + 母公司财务报表（同一套会计准则、不同列报范围）
- **列示维度**：
  - 资产负债表：报告日（期末/期初两期对比）
  - 利润表/现金流量表：报告期间（本期/上期两期对比）
- **口径**：所有金额单位为人民币元（特殊情况除外）；保留两位小数

### 修订历史

| 年份 | 主要文件 | 关键变化 |
|---|---|---|
| 2006 | 企业会计准则体系 | 体系基本建立 |
| 2014 | 财会〔2014〕6 号、10 号 | 引入"综合收益"；"应付票据及应付账款"等合并项目；库存股作为减项 |
| 2017 | 财会〔2017〕22 号 | 新增"其他收益"、"资产处置收益"；"营业税金及附加"改名"税金及附加" |
| 2018 | 财会〔2018〕15 号 | "研发费用"独立列示 |
| 2019 | 财会〔2019〕6 号、16 号 | "应收款项融资"、"使用权资产"、"租赁负债"、"信用减值损失"等新增；"应付/应收票据"与"应付/应收账款"再次拆分 |
| 2023 | 财会〔2023〕21 号（解释 17 号） | 流动 vs 非流动划分、供应商融资安排 |
| 2024 | 财会〔2024〕24 号（解释 18 号） | 现金流量表若干项目列示优化；"数据资源"作为存货/无形资产/开发支出明细项 |

### 三大报表的勾稽关系

```
合并资产负债表：
    资产总计 = 负债合计 + 所有者权益合计 = 负债和所有者权益总计

合并利润表：
    净利润 = 持续经营净利润 + 终止经营净利润
          = 归属于母公司股东的净利润 + 少数股东损益

合并现金流量表：
    期末现金及现金等价物余额 = 期初 + 净增加
    净增加 = 经营净额 + 投资净额 + 筹资净额 + 汇率影响
```
