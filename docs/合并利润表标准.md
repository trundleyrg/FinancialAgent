# 合并利润表（Consolidated Income Statement）标准格式

> 编制依据：《企业会计准则第 30 号——财务报表列报》（财会〔2014〕6 号）
> 修订依据：《关于修订印发合并财务报表格式（2019 版）的通知》（财会〔2019〕16 号）
> 适用范围：在中华人民共和国境内设立的、执行企业会计准则的上市公司与非上市企业，编制合并及母公司利润表。

## 一、整体结构与计算逻辑

利润表为**流量表**，反映企业在一定会计期间（年度/中期/季度）的经营成果。

```
营业总收入  -  营业总成本  ±  各种收益/损失  =  营业利润
营业利润  +  营业外收入  -  营业外支出  =  利润总额
利润总额  -  所得税费用  =  净利润
净利润  +  其他综合收益(税后)  =  综合收益总额
```

列示维度：报告期间（如"2024 年度"）。报表至少列示两期数据：
- 本期发生额
- 上期发生额

## 三、合并利润表与母公司利润表的差异

| 项目 | 合并利润表 | 母公司利润表 |
|---|---|---|
| 营业收入 | 含子公司收入 | 仅母公司自身收入 |
| 投资收益 | 含按权益法确认的对联营/合营企业投资收益 | 含对子公司的分红、成本法核算收益 |
| 净利润 | 含少数股东损益 | 仅母公司股东应享净利润 |
| 综合收益 | 归属于母公司 + 归属于少数股东 | 全部归属于母公司 |

## 四、与现有 ORM 模型的对照

`src/db/models.py` 的 `ConsolidatedIncomeStatement` 模型**基本完整**覆盖本表项目。需核对和补齐的点：

1. **项目顺序**：与本文件"营业总收入→营业总成本→加项→营业利润→营业外→利润总额→所得税→净利润→综合收益→每股收益"顺序一致
2. **细分项（如营业外支出下的"非流动资产处置损失"）**：暂未作为独立字段，因为发生概率低；可后续扩展
3. **研发费用列示**：已从"管理费用"中拆出，独立列示 ✅
4. **汇兑收益**：当前模型缺失；金融行业报表需要，建议补齐
5. **括号说明（"-"号填列）**：仅在文档或说明中体现，DB 字段允许正负
