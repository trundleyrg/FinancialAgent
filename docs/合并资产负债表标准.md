# 合并资产负债表（Consolidated Balance Sheet）标准格式

> 编制依据：《企业会计准则第 30 号——财务报表列报》（财会〔2014〕6 号）
> 修订依据：《关于修订印发合并财务报表格式（2019 版）的通知》（财会〔2019〕16 号）
> 适用范围：在中华人民共和国境内设立的、执行企业会计准则的上市公司与非上市企业，编制合并及母公司资产负债表。

## 一、整体结构

```
            ┌───────────────────────────┐
            │       资 产 负 债 表       │
            ├──────────┬────────────────┤
            │   资产   │   负债 + 权益  │
            ├──────────┼────────────────┤
            │ 流动资产  │   流动负债      │
            │ 非流动资产│   非流动负债    │
            │          │   所有者权益    │
            ├──────────┼────────────────┤
            │ 资产总计  │ 负债和权益总计   │
            └──────────┴────────────────┘
```

恒等式：**资产总计 = 负债合计 + 所有者权益合计 = 负债和所有者权益总计**

列示维度：报告日（资产负债表日）。报表至少列示两期数据：
- 期末余额（本报告日）
- 期初余额（上一报告日；上市公司年初余额或上年末余额）

## 五、合并报表与母公司报表的差异

| 项目 | 合并报表 | 母公司报表 |
|---|---|---|
| 长期股权投资 | 按权益法核算合并子公司结果 | 按成本法核算对子公司投资 |
| 内部往来 | 已抵消 | 保留 |
| 子公司投资差额 | 商誉（合并成本大于可辨认净资产公允价值） | 不适用 |
| 少数股东权益 | 单列 | 不存在 |

## 六、与现有 ORM 模型的对照

`src/db/models.py` 的 `ConsolidatedBalanceSheet` 模型基本覆盖本表全部主要项目。
需要核对和补齐的点：

1. **字段缺失**：目前缺「合同负债」前的细化项（即「预收款项」）✅已有；新增「使用权资产」「租赁负债」✅已有
2. **行业专用项**：金融业（结算备付金、拆出资金等）、保险业（应收分保账款等）项目已纳入；模型需保留以便统一存储所有上市公司报表
3. **统一命名**：建议中文 help_text 与本文件的中文项目名称完全一致
4. **恒等式校验**：数据写入或读取时，应保证 `资产总计 == 负债合计 + 所有者权益合计`
