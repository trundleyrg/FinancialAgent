# 合并现金流量表（Consolidated Cash Flow Statement）标准格式

> 编制依据：《企业会计准则第 31 号——现金流量表》（2006 版，2014 年修订应用指南）
> 修订依据：《关于修订印发合并财务报表格式（2019 版）的通知》（财会〔2019〕16 号）
> 适用范围：在中华人民共和国境内设立的、执行企业会计准则的上市公司与非上市企业，编制合并及母公司现金流量表。

## 一、整体结构与编制原则

现金流量表反映企业在一定会计期间的**现金及现金等价物**的流入与流出，按经济活动性质分为三大类：

```
一、经营活动产生的现金流量  →  经营活动现金流入小计 - 流出小计 = 净额
二、投资活动产生的现金流量  →  投资活动现金流入小计 - 流出小计 = 净额
三、筹资活动产生的现金流量  →  筹资活动现金流入小计 - 流出小计 = 净额
四、汇率变动对现金及现金等价物的影响
五、现金及现金等价物净增加额 = 经营净额 + 投资净额 + 筹资净额 + 汇率影响
加：期初现金及现金等价物余额
六、期末现金及现金等价物余额 = 期初 + 净增加
```

### 1.1 三大活动划分原则

| 活动 | 判定标准 | 典型业务 |
|---|---|---|
| 经营活动 | 与企业净利润相关的、非常规的投资和筹资以外的活动 | 销售商品、支付薪酬、缴纳税费 |
| 投资活动 | 与长期资产（固定资产、无形资产、长期股权）取得/处置/减值相关；与现金等价物以外的金融资产投资相关 | 购建固定资产、收购子公司、购买债券 |
| 筹资活动 | 与企业资本结构（借款、股本、债券）变动相关 | 取得借款、发行股票、偿还债务、分配股利 |

### 1.2 列示维度

- **本期发生额**（当期累计，如"2024 年度"）
- **上期发生额**（上期同期累计）

## 三、补充资料（间接法调节）

对于经营活动产生的现金流量净额，准则允许采用**直接法**或**间接法**编制。采用间接法时，应在报表附注披露：

```
净利润
± 资产减值准备
± 固定资产折旧、无形资产摊销、长期待摊费用摊销
± 处置固定资产/无形资产/其他长期资产的损失
± 固定资产报废损失
± 公允价值变动损失
± 财务费用
± 投资损失
± 递延所得税资产/负债变动
± 存货的减少（增加以"-"号填列）
± 经营性应收项目的减少（增加以"-"号填列）
± 经营性应付项目的增加（减少以"-"号填列）
= 经营活动产生的现金流量净额
```

## 四、与现有 ORM 模型的对照

`src/db/models.py` 的 `ConsolidatedCashFlowStatement` 模型覆盖了**所有主要项目**及常用明细项。需核对和补齐的点：

1. **完整性**：经营活动、投资活动、筹资活动三大类 50+ 项目均已建模 ✅
2. **行业专用项**：金融/保险/证券企业的特殊项目（如结算备付金、拆出资金、代理买卖证券款、保户储金等）已建模
3. **业务细分**：
   - 取得投资收益收到的现金 ✅
   - 处置子公司净额 ✅
   - 吸收投资 vs 取得借款 ✅
   - 偿还债务 vs 分配股利 ✅
4. **现金等价物**：期初/期末、净增加、汇率影响 ✅
