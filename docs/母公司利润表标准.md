# 母公司利润表（Parent Company Income Statement）标准格式

> 编制依据：《企业会计准则第 30 号——财务报表列报》（财会〔2014〕6 号）
> 修订依据：《关于修订印发合并财务报表格式（2019 版）的通知》（财会〔2019〕16 号）
> 适用范围：在中华人民共和国境内设立的、执行企业会计准则的上市公司与非上市企业，编制母公司利润表。

## 一、与合并利润表的关键差异

| 项目 | 母公司利润表 | 合并利润表 |
|---|---|---|
| **视角** | 单一法人（母公司自身） | 集团合并（含子公司） |
| **营业收入结构** | 简单"营业收入"为主，可包含"营业总收入"汇总 | "营业总收入"汇总（含金融业利息收入等） |
| **项目编号** | 一/二/三/四/五/六/七 | 一/二/三/四/五/六/七/八（多一项"每股收益"编号八） |
| **按所有权归属分类** | **不存在**（无"少数股东损益"、无"归属于母公司股东的净利润"） | **存在**（净利润分为归属母公司 + 少数股东） |
| **投资收益** | 主要为子公司分红（成本法下确认） | 含权益法核算的对联营/合营企业投资收益 |
| **所得税费用** | 母公司自身所得税 | 含子公司所得税（各自计税） |
| **综合收益归属** | **不区分**母公司/少数股东 | 区分归属母公司 / 归属少数股东 |

## 三、合并 vs 母公司 利润表编号对照

| 编号 | 合并利润表 | 母公司利润表 |
|---|---|---|
| 一 | 营业总收入 | **营业收入**（或营业总收入） |
| 二 | 营业总成本 | **营业利润** |
| 三 | 营业利润 | **利润总额** |
| 四 | 利润总额 | **净利润** |
| 五 | 净利润 | **其他综合收益的税后净额** |
| 六 | 其他综合收益的税后净额 | **综合收益总额** |
| 七 | 综合收益总额 | **每股收益** |
| 八 | 每股收益 | （不存在） |

## 四、与现有 ORM 模型的对照

`src/db/models.py` 的 `ParentCompanyIncomeStatement` 模型**已基本覆盖本表项目**。需核对与补齐的点：

1. **编号一致性**：当前模型 `operating_profit` help_text 写"二、营业利润"（合并表为"三、营业利润"）—— 已在最新代码中正确标注为"二、营业利润" ✅
2. **缺失项**：
   - **新增**：与合并表一致，应补充 `non_operating_income_from_asset_disposal`、`non_operating_expenses_from_asset_disposal`、`oci_unrecognized_other`、`exchange_gains`、`financial_asset_derecognition_income`、`net_hedge_gain`
3. **错误项**：
   - 当前模型有 `interest_expense` 与 `interest_income` 字段，但 help_text 都写"利息支出"与"利息收入"，无区分。建议分别加注（合并表已修正）
4. **应删除的字段**（不应出现在母公司报表）：
   - `net_profit_attributable_to_parent`（无少数股东，不需划分）
   - `minority_interest_net_profit`
   - `other_comprehensive_income_attributable_to_parent`
   - `oci_attributable_to_minority`
   - `comprehensive_income_attributable_to_parent`
   - `comprehensive_income_attributable_to_minority`
