# 母公司资产负债表（Parent Company Balance Sheet）标准格式

> 编制依据：《企业会计准则第 30 号——财务报表列报》（财会〔2014〕6 号）
> 修订依据：《关于修订印发合并财务报表格式（2019 版）的通知》（财会〔2019〕16 号）
> 适用范围：在中华人民共和国境内设立的、执行企业会计准则的上市公司与非上市企业，编制母公司资产负债表。

## 一、与合并资产负债表的关键差异

| 项目 | 母公司资产负债表 | 合并资产负债表 |
|---|---|---|
| **长期股权投资** | 按**成本法**核算，全额列示对子公司、联营、合营企业投资 | 抵消后**仅保留**对联营/合营企业投资（按权益法） |
| **少数股东权益** | **不存在**（母公司报表反映单一法人视角） | 在所有者权益中单列 |
| **归属于母公司所有者权益合计** | **不存在**（无母公司/少数之分） | 在所有者权益中单列 |
| **归属于母公司所有者权益（或股东权益）合计** | **不存在** | 单列；与之并列"少数股东权益" |
| **内部应收/应付** | 完整列示（不抵消内部往来） | 已抵消 |
| **未实现内部交易损益** | 不调整 | 在合并工作底稿中抵消 |
| **商誉** | **不存在**（投资按成本法计量） | 合并成本超过享有可辨认净资产公允价值份额的差额 |
| **项目结构** | 完全相同 | 完全相同 |

## 五、与现有 ORM 模型的对照

`src/db/models.py` 的 `ParentCompanyBalanceSheet` 模型**已基本覆盖本表项目**。需核对与补齐的点：

1. **缺失项**：
   - 「应付股利」（目前与合并表一致，仅「其中：应付股利」）✅ 已有
   - 「应付债券 — 其中：优先股 / 永续债」✅ 已有
   - 「使用权资产 / 租赁负债（2019 版新增）」✅ 已有
2. **关键差异**：
   - **商誉**：当前模型包含 `goodwill` 字段，但母公司报表不应有商誉——保留字段无业务发生即可，不必删除
   - **所有者权益结构**：当前模型已正确**无** `minority_interest` 与 `total_equity_attributable_to_parent_company`，符合母公司视角 ✅
3. **行业专用项**：母公司报表与合并表均含相同行业专用项（金融/保险/证券等），保留统一存储
4. **未分配利润**：母公司报表的"未分配利润"**不等于**合并报表——母公司报表为母公司自身的累计未分配利润（成本法下子公司分红会回流到母公司投资收益）
