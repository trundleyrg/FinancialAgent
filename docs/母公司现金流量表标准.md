# 母公司现金流量表（Parent Company Cash Flow Statement）标准格式

> 编制依据：《企业会计准则第 31 号——现金流量表》（2006 版）
> 修订依据：《关于修订印发合并财务报表格式（2019 版）的通知》（财会〔2019〕16 号）
> 适用范围：在中华人民共和国境内设立的、执行企业会计准则的上市公司与非上市企业，编制母公司现金流量表。

## 一、与合并现金流量表的关键差异

| 项目 | 母公司现金流量表 | 合并现金流量表 |
|---|---|---|
| **视角** | 单一法人（母公司自身） | 集团合并（含子公司） |
| **经营活动现金流入** | 母公司自身销售/服务相关 | 含集团内公司间交易 |
| **经营活动现金流出** | 母公司自身成本/费用/税费 | 含集团内公司间交易 |
| **取得投资收益收到的现金** | **核心差异**：主要为**子公司宣告分派的现金股利/利润**（成本法下） | 含权益法下对联营/合营企业的现金股利 |
| **处置子公司及其他营业单位收到的现金净额** | 母公司处置子公司股权的现金净额 | 同上 |
| **取得子公司及其他营业单位支付的现金净额** | 母公司取得子公司股权的现金净额 | 同上 |
| **"其中：子公司吸收少数股东投资收到的现金"** | **不存在**（母公司报表无少数股东概念） | 存在 |
| **"其中：子公司支付给少数股东的股利、利润"** | **不存在** | 存在 |
| **集团内部资金往来** | 完整列示（不抵消） | 合并工作底稿中抵消 |

## 二、母公司现金流量表标准项目

### 2.1 一、经营活动产生的现金流量

#### 经营活动现金流入

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 1 | 销售商品、提供劳务收到的现金 | 母公司自身销售商品/提供劳务 |
| 2 | 收到的税费返还 | 增值税出口退税等 |
| 3 | 收到其他与经营活动有关的现金 | |
| **4** | **经营活动现金流入小计** | **小计** |

#### 经营活动现金流出

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 5 | 购买商品、接受劳务支付的现金 | |
| 6 | 支付给职工及为职工支付的现金 | |
| 7 | 支付的各项税费 | |
| 8 | 支付其他与经营活动有关的现金 | |
| **9** | **经营活动现金流出小计** | **小计** |
| **10** | **经营活动产生的现金流量净额** | **净额** |

> 母公司报表的经营活动现金流量**不含**集团内子公司业务，金额通常显著小于合并表。

### 2.2 二、投资活动产生的现金流量

#### 投资活动现金流入

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 11 | 收回投资收到的现金 | 母公司收回的对外投资本金 |
| 12 | **取得投资收益收到的现金** | **母公司报表核心**：主要为子公司宣告分派的现金股利 |
| 13 | 处置固定资产、无形资产和其他长期资产收回的现金净额 | |
| 14 | 处置子公司及其他营业单位收到的现金净额 | 母公司处置子公司股权所得 |
| 15 | 收到其他与投资活动有关的现金 | 母公司收回的内部借款等 |
| **16** | **投资活动现金流入小计** | **小计** |

#### 投资活动现金流出

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 17 | 购建固定资产、无形资产和其他长期资产支付的现金 | 母公司自身资本性支出 |
| 18 | 投资支付的现金 | **母公司报表核心**：对外投资（含对子公司增资） |
| 19 | 取得子公司及其他营业单位支付的现金净额 | 母公司取得/收购子公司股权 |
| 20 | 支付其他与投资活动有关的现金 | 母公司借出的内部资金等 |
| **21** | **投资活动现金流出小计** | **小计** |
| **22** | **投资活动产生的现金流量净额** | **净额** |

### 2.3 三、筹资活动产生的现金流量

#### 筹资活动现金流入

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 23 | 吸收投资收到的现金 | 母公司增发/配股收到现金 |
| 24 | 取得借款收到的现金 | 母公司自身借款 |
| 25 | 收到其他与筹资活动有关的现金 | 可能含集团内部资金往来 |
| **26** | **筹资活动现金流入小计** | **小计** |

#### 筹资活动现金流出

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 27 | 偿还债务支付的现金 | 母公司自身偿债 |
| 28 | 分配股利、利润或偿付利息支付的现金 | 母公司向自身股东分红 |
| 29 | 支付其他与筹资活动有关的现金 | 母公司发行费用、租赁付款等 |
| **30** | **筹资活动现金流出小计** | **小计** |
| **31** | **筹资活动产生的现金流量净额** | **净额** |

> 母公司报表**不**含合并表中"其中：子公司吸收少数股东投资收到的现金"与"其中：子公司支付给少数股东的股利、利润"。

### 2.4 四、汇率变动及现金净增加额

| 序号 | 项目名称 | 备注 |
|---|---|---|
| 32 | 四、汇率变动对现金及现金等价物的影响 | |
| 33 | 五、现金及现金等价物净增加额 | = 经营净额 + 投资净额 + 筹资净额 + 汇率影响 |
| 34 | 加：期初现金及现金等价物余额 | |
| 35 | 六、期末现金及现金等价物余额 | = 期初 + 净增加 |

## 三、与现有 ORM 模型的对照

`src/db/models.py` 的 `ParentCompanyCashFlowStatement` 模型**基本覆盖本表项目**。需核对与补齐的点：

1. **应删除的字段**（合并表专有，母公司无）：
   - `capital_contribution_from_minority` — "其中：子公司吸收少数股东投资收到的现金"
   - `dividend_to_minority` — "其中：子公司支付给少数股东的股利、利润"
2. **金融/保险专用项目**：母公司报表与合并表通常均不列示（除非母公司本身就是金融机构），建议保留字段统一存储
3. **错误项**：
   - 当前 `cash_from_subsidiary_disposal` 的 help_text 含有英文 "the cash net"，应清理
4. **完整性**：母公司报表的核心项目（取得投资收益收到的现金、投资支付的现金、处置/取得子公司净额）均已建模 ✅
